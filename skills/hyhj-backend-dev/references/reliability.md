# 可靠性与验证

涉及外部调用、长任务、并发执行、流式响应、运维或发布时读取。先说明失败会影响什么，再选择必要机制；普通请求不强制升级成复杂任务平台。

## 外部调用与超时预算

从调用方等待时间、下游特征和业务容忍度确定超时，不套用固定数值。

- 区分连接、读取、单次调用和任务总截止时间，避免每层重试耗尽整体预算。
- 为需要的依赖定义不可用行为：明确失败、排队或有业务含义的降级。
- 降级结果标记能力与数据边界，不能以空列表伪装真实数据不存在。
- 后台工作限制并发、队列和资源占用，饱和时给出可解释的拒绝或等待状态。
- 线程池、连接池或异步并发采用项目已有的可控方式，按实际瓶颈调优。

## 重试与不确定副作用

先判断失败发生在提交之前、执行之中，还是响应返回途中。
网络超时可能意味着对方已经执行；结果未知时先查询、核对或人工处理。

- 仅对适合重试的暂时失败重试，设定次数、退避和整体时间上限。
- 校验错误、权限拒绝和确定性业务失败不自动反复提交。
- 外部写入记录可核对的提交身份和状态；重试不得绕过幂等或再次确认约束。
- 对方没有幂等能力时，不能仅凭本地重试次数保证“只执行一次”。
- 不确定结果保持为明确的未知/待核对状态，不能随意标成功或当作未执行。
- 既有用户授权在原范围内继续有效；参数或副作用范围实质改变时按需求重新确认。

## 异步任务、取消与流式状态

长耗时任务需要时才持久化状态、进度和结果；状态机应体现业务真实进展。

- 区分已接收、运行中、完成、失败和取消；业务成功由所属业务用例决定。
- 每个任务有可查询的归属、状态及结果，查询与取消仍需授权。
- 避免同一资源并发执行互斥操作，或明确允许并行时的版本和冲突规则。
- 取消信号需要传播到可中止操作，同时处理清理、锁释放和资源回收。
- 取消不天然回滚已提交数据或已发生的外部副作用，结果中说明实际状态。
- Worker 中断与任务重入需按风险设计恢复方式，避免重复外部写入。
- 流式连接断开是否取消任务由产品语义决定，不默认将二者等同。
- 若允许恢复订阅，使用有序事件和游标等项目现有机制，核对丢失、重复与终态。
- 不因某个项目曾选用某种终态规则而禁止其他项目的重试或恢复功能。

## 日志、追踪与运行检查

记录足以连接请求、任务、数据对象和下游调用的关联标识。
日志、指标与追踪按当前系统接入，不为小变更新建整套观测平台。

- 预期业务失败与系统错误分开，稳定错误码与用户提示各司其职。
- 不记录密码、令牌、密钥、完整私密正文或不必要的个人数据。
- 外部请求/响应不能无差别整包落日志，调试日志也要控制内容和保留范围。
- 关注错误率、延迟、资源饱和及任务积压中与本次风险相关的信号。
- 进程存活检查与可服务检查分开；关键依赖不可用时不能仍宣称业务就绪。
- 对选配能力说明其降级语义，避免把所有非必要依赖都变为启动阻塞项。

## 按风险验证

从可观察行为出发，优先使用项目已有测试和运行入口。

| 变化 | 优先验证 |
|---|---|
| 业务规则 | 正常输入、边界、拒绝原因和重要不变量 |
| 接口重构 | 声明契约，以及认证、权限、错误或副作用的相关行为 |
| 数据写入 | 真实写入、独立读取、约束和必要的冲突处理 |
| 异步/外部写入 | 重复提交、超时、未知结果、取消或中断后的实际状态 |
| 迁移/发布 | 结构变化、新旧兼容、健康检查及所需恢复路径 |

隔离替身可以稳定复现错误和边界；标明未覆盖的网络、凭据、真实存储及第三方协议。
需要证明集成时使用有授权的测试资源和最小必要操作，不调用未授权的真实业务写入。
只改注释或低影响说明时，核对内容即可，不为了“有测试”编写复述实现的断言。
相关检查通过后，除非出现新改动或新疑点，不重复全量回归。

## 真实持久化与恢复证据

- 写入后从独立请求或会话读取，避免只检查同一进程中的临时对象。
- 对存在缓存的路径确认读到的层级，必要时验证持久层或适当的重启场景。
- 实际使用什么数据库、对象存储或外部沙箱就报告什么，不能将内存替身改名为真实验证。
- 存储未连通或权限不足时，明确哪些检查未执行，并继续完成其他可核验部分。
- 有数据损坏或丢失风险时，核对恢复入口与备份可用性；深度由任务风险决定。

## 发布与交接

部署只在任务已有授权范围内执行，既有授权不重复询问。
没有部署授权时，完成可审查的实现和发布说明，不自行发布。

- 使用仓库已有的构建、迁移、健康与冒烟流程，记录实际完成情况。
- 配置示例只含占位值，运行配置与凭据不进入公开提交或输出。
- 数据结构变化前明确备份、兼容窗口和失败处置，避免承诺不可实现的一键回滚。
- 变更外部副作用时，说明回滚代码不能撤回的业务动作及核对方式。
- 热修复需要回归版本控制与正常评审路径，避免服务器成为唯一代码来源。
- 交接提供定位故障需要的启动入口、日志/任务查询方式和仍未覆盖的验证边界。
